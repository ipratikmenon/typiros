# Kernel

The OS / ROM layer. In early phases this is just the host Linux system
(PinePhone / Linux Mobile in Phase 1). In Phase 4, this becomes a custom
AOSP-based ROM hosting the Android compatibility container alongside the
typirOS shell and Tier 1 runtime.

See [PRD.md § 16](../PRD.md#16-build-phases) (Phase 4 — Hardening + Custom ROM).
